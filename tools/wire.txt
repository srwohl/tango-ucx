# The wire of tango-ucx, as tools/check.py checks it against src/transport/wire.cpp.
#
# 0.1 is a pre-release, to be continued until 1.0: until then an entry may still change, and a
# reader accepts only its own version. From 1.0 these rules hold, after protobuf's:
#   - an entry is never renamed, retyped, moved or given another meaning;
#   - a new key is optional, and its absence means what it meant before the key existed;
#   - a new binary field goes at the end of its message; readers ignore bytes they do not know;
#   - a reader keeps an enum value it does not know, and treats it as a failure, not as 0;
#   - a removed entry becomes `retired` and its name is never used again.
#
# key <document> <name> <type>             a JSON key; documents: open close reply stream
#                                          sessions (sessions.row: each entry of "sessions")
#                                          topology (topology.device: each network device)
# enum <name> <value>                      sent by name, never by number
# field <message> <offset> <name> <type>   a little-endian data-plane field; `reserved` is
#                                          zero when sent and ignored when read
# retired key <name>                       never to be used again

# Ready (SessionMessage), 8 bytes.
field SessionMessage 0 session u64
# Frame, 40 bytes then the record; an opaque stream's has its position first, 48 bytes.
field FrameMessage 0 session u64
field FrameMessage 8 sequence u64

field FrameMessage 24 index u64

# End, 40 bytes.
